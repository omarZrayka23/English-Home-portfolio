# 🛒 E-Commerce Platform

A full-stack e-commerce platform for managing products, customers, orders, and online shopping.

### 🛠️ Technologies

* **Frontend:** Next.js, Tailwind CSS
* **Backend:** PHP REST API
* **Database:** MySQL

### ✨ Features

* Product browsing and categories
* Shopping cart
* Customer accounts
* Order management
* Responsive design
* REST API integration
* Admin management
